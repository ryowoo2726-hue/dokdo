# 마석중학교 독도 퀴즈

- 퀴즈: https://dokdo.sangsangbar.com
- 랭킹: https://dokdo.sangsangbar.com/ranking.html
- API: https://dokdo-api.sangsangbar.com → Cloudflare Tunnel → 노트북 127.0.0.1:8787

## 파일 구성

```text
public/                 배포할 화면 파일만 보관
  index.html            태블릿 가로형 퀴즈·학생 정보 입력
  ranking.html          실시간 랭킹
  css/                  공통·랭킹 스타일
  js/                   퀴즈·랭킹·공통 API 설정·브라우저 채점
  data/questions.json   문제·정답·해설
  assets/               실제 화면에서 사용하는 SVG
home-server/            SQLite 저장·랭킹 API·터널 운영
scripts/                빌드·로컬 미리보기 서버
tests/                  임시 DB 기반 서버·연결 테스트
design/reference-assets/ 디자인 원본 참고 에셋 (배포 제외)
```

루트의 배치 파일은 실행 편의를 위해 유지합니다. `dist/`는 자동 생성된 배포 결과이며 Git에서 제외합니다. 이전 미리보기·캐시·정리 도구는 `.local-archive/`에 보관하며 Git과 배포에서 제외합니다.

## 행사 운영

1. `start-event.bat`: 노트북 서버·Cloudflare 터널·실행 중 절전 방지를 함께 시작합니다.
   시작하면 http://127.0.0.1:8788/ 서버 관리 창이 자동으로 열립니다. 새로고침·서버 종료 버튼과 최근 50건의 접수 목록을 제공합니다.
2. 서버 창에서 Enter 또는 Ctrl+C: 서버와 터널을 함께 종료합니다.
3. 노트북을 충전기에 연결하고 덮개를 열어 둡니다. Windows 서비스나 재부팅 자동 실행은 설치하지 않습니다.
4. 코드나 문제 파일을 변경했다면 서버를 재시작합니다.

학생 응답이 저장되면 CMD에 `접수 시각 | 학년·반·번호 | 닉네임 | 누적 인원`이 한 줄씩 표시됩니다. 같은 답안의 재전송은 새 접수로 중복 출력하지 않습니다. 관리 창의 새로고침 또는 CMD에서 `R` + Enter를 누르면 최근 10건을 다시 출력합니다. 관리 창은 2초마다 자동 갱신하며 노트북의 로컬 주소에서만 접근할 수 있습니다.

터널을 처음 설정할 때만 `setup-tunnel.bat`을 실행합니다. 서버가 꺼져 있으면 퀴즈 시작·제출을 할 수 없고 랭킹은 빈 목록으로 표시됩니다.

## 로컬 확인

- `start.bat` 또는 `npm start`: 로컬 API 시작
- 다른 창에서 `preview.bat` 또는 `npm run dev`: 로컬 화면 시작
- 퀴즈: http://127.0.0.1:4173/
- 랭킹: http://127.0.0.1:4173/ranking.html
- 상태: http://127.0.0.1:8787/health

미리보기 서버는 `public/`만 제공하고 `/api/`를 노트북 API로 전달합니다. 로컬과 배포 화면은 `public/js/api.mjs`의 같은 설정을 사용합니다. 개발 미리보기는 로컬 컴퓨터에만 바인딩됩니다.

## 저장·랭킹

- 학년·반·번호 조합으로 최초 제출 한 번만 저장합니다. 닉네임은 1~20자이며 바꾸어도 중복 참여 제한은 유지됩니다.
- 저장 내용: 접수번호, 학년·반·번호, 닉네임, 선택 답안, 문제 버전, 시작·접수 시각. 저장이 완료된 후 브라우저에서 점수와 해설을 보여줍니다.
- `GET /api/rankings`는 현재 문제 버전의 답안을 서버에서 채점해 순위·학년·반·번호·닉네임·점수만 반환합니다. 답안 원문과 접수번호는 공개하지 않습니다.
- 점수 내림차순, 동점은 공동 순위(1, 1, 3), 같은 점수는 접수 순서입니다. 이전 기록에 닉네임이 없으면 대시(—)로 표시합니다.
- 랭킹은 10초마다 갱신하고, 연결 실패·시간 초과·잘못된 응답이면 이전 목록도 비웁니다. 목록이 길면 초당 약 18px로 이동하며, 정지 버튼과 동작 줄이기 설정을 지원합니다.
- 집계 결과는 새 제출이 저장될 때만 다시 계산합니다. 데이터가 그대로면 화면 목록도 다시 만들지 않습니다. 빈 목록·정지 상태·숨겨진 탭에서는 자동 스크롤 프레임을 실행하지 않습니다.
- 신원 인증은 없습니다. 기존 DB와 이전 참여 제한은 그대로 보존합니다. 테스트는 별도의 임시 DB를 사용합니다.

저장 위치: `C:\scr\dokdo\responses.sqlite` (`DOKDO_DATA_DIR` 환경 변수로 변경 가능)

`export.bat`으로 학번·닉네임·문제 버전·선택번호 CSV를 `C:\scr\dokdo\exports`에 내보냅니다. CSV에는 점수를 저장하지 않으며, 닉네임이 수식으로 실행되지 않도록 처리합니다. 백업은 서버를 끈 후 저장 폴더 전체를 복사합니다. 기존 `%LOCALAPPDATA%\MaseokDokdo`의 응답과 CSV는 새 위치로 이전했고, 원래 파일과 `C:\scr\dokdo\backups`의 이전 전 DB 사본을 보존합니다.

터널 설정: `%LOCALAPPDATA%\MaseokDokdo\tunnel\config.yml`

Cloudflare 인증: `%USERPROFILE%\.cloudflared` (Git·배포 제외)

## 검증·배포

- `npm test`: 500명 저장, 동시 제출·중복 경합·재시도·재시작·이전 기록·닉네임·랭킹·CORS·로컬 API 연결 검사
- `npm run build`: `public/`만 `dist/`로 복사하고 배포 CSS의 주석·불필요한 공백을 제거합니다. 정적 SVG에는 캐시를 적용합니다.
- 외부 폰트 다운로드 없이 시스템 한글 폰트를 사용합니다.
- Pages 프로젝트: `maseok-dokdo`, 저장소: `ryowoo2726-hue/dokdo`, 배포 브랜치: `main`
- Pages 빌드: `npm run build`, 출력: `dist`, 프레임워크: None

문제·정답은 공개 파일입니다. `public/data/questions.json`을 바꾸면 화면을 배포하고 노트북 서버도 재시작해야 합니다. 브라우저와 서버는 같은 문제 데이터의 SHA-256 버전을 사용합니다.

허용 출처는 학생 도메인·Pages 기본 도메인·로컬 API 주소입니다. `DOKDO_ALLOWED_ORIGINS`로 정확한 출처 목록을 설정할 수 있습니다. 학교 Wi-Fi와 외부 네트워크의 동시 부하는 현장에서 별도로 확인해야 합니다.
