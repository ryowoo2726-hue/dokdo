# 마석중학교 독도 퀴즈

- 퀴즈: https://dokdo.sangsangbar.com
- 랭킹: https://dokdo.sangsangbar.com/ranking.html
- API: https://dokdo-api.sangsangbar.com → Cloudflare Tunnel → 노트북 127.0.0.1:8787

  css/ranking.css       실시간 랭킹

  assets/figma/         현재 피그마에서 내보낸 화면용 그림

루트의 배치 파일은 실행 편의를 위해 유지합니다. `dist/`는 자동 생성된 배포 결과이며 Git에서 제외합니다. 이전 미리보기·캐시·정리 도구는 `.local-archive/`에 보관하며 Git과 배포에서 제외합니다.

## 행사 운영

1. `start-event.bat`: 독립된 관리 프로그램과 퀴즈 서버·Cloudflare 터널·실행 중 절전 방지를 함께 시작합니다.
   시작하면 http://127.0.0.1:8788/ 서버 관리 창이 자동으로 열립니다. 서버 켜기·끄기·재시작·상태 새로고침과 최근 50건의 접수 목록을 제공합니다.
2. 서버 창에서 Q + Enter 또는 Ctrl+C: 관리 프로그램·퀴즈 서버·터널을 모두 종료합니다. 관리 페이지의 **서버 끄기**는 퀴즈 서버만 끄므로 원격으로 다시 켤 수 있습니다.
3. 노트북을 충전기에 연결하고 덮개를 열어 둡니다. Windows 서비스나 재부팅 자동 실행은 설치하지 않습니다.
4. 코드나 문제 파일을 변경했다면 서버를 재시작합니다.

학생 응답이 저장되면 CMD에 `접수 시각 | 학년·반·번호 | 닉네임 | 누적 인원`이 한 줄씩 표시됩니다. 같은 답안의 재전송은 새 접수로 중복 출력하지 않습니다. 관리 창의 상태 새로고침 또는 CMD에서 `R` + Enter를 누르면 최근 10건을 다시 출력합니다. 관리 창은 2초마다 자동 갱신합니다. 퀴즈 서버가 정지 중이면 마지막으로 확인한 학생 목록을 보여 줍니다.

`start-event.bat`으로 켜둔 동안 퀴즈 서버 오류 종료를 감지하면 자동으로 복구합니다. 서버 상태도 5초마다 확인해 세 번 연속 응답하지 않으면 재시작합니다. 첫 재시도는 3초 후이며 반복 실패 시 최대 30초 간격으로 늘립니다. 터널 종료 시에는 별도로 5초 후 재연결합니다. DB는 그대로 사용하며 관리 창의 자동 복구 상태와 재시작 횟수도 갱신됩니다.

관리 창의 **서버 끄기**는 자동 복구도 멈추고 **서버 켜기**로 다시 실행합니다. CMD의 **Q·Ctrl+C**로 관리 프로그램까지 종료하면 원격으로 켤 수 없습니다. Windows 부팅 시 자동 실행하지 않습니다. 작업 관리자에서 내부 퀴즈 서버 프로세스만 강제 종료하는 경우는 장애로 간주합니다. `start.bat`·`npm start`로 실행한 개발용 API에는 자동 복구가 적용되지 않습니다.

터널을 처음 설정할 때만 `setup-tunnel.bat`을 실행합니다. 서버가 꺼져 있으면 퀴즈 시작·제출을 할 수 없고 랭킹은 빈 목록으로 표시됩니다.

## 휴대폰·웹 원격 관리

- 기존 터널을 사용 중이면 `setup-remote.bat`을 한 번 실행해 관리 주소를 추가합니다. 기존 설정은 로컬 백업으로 보존합니다.
- 노트북에서 `start-event.bat` 실행 후 관리 화면의 **이 노트북에서 확인**을 눌러 관리 비밀번호를 확인합니다.
- 휴대폰 또는 다른 PC에서 https://dokdo-admin.sangsangbar.com/ 에 접속해 관리 아이디와 비밀번호로 로그인합니다. 서버 켜기·끄기·재시작·새로고침이 가능합니다.
- 비밀번호는 저장된 해시로 검증합니다. 최초 설정 시 무작위 비밀번호를 생성하며 실제 운영 인증 정보는 노트북의 로컬 설정을 사용합니다. 원격 세션은 8시간 후 만료되며 로그아웃 시 즉시 폐기됩니다. 반복 로그인 시도를 제한하고 다른 출처에서의 제어 요청을 차단합니다.
- 인증 설정과 비밀번호는 `%LOCALAPPDATA%\MaseokDokdo\remote`에 보관하며 저장소·학생 사이트 배포에 포함하지 않습니다. 비밀번호 확인은 노트북의 로컬 관리 화면에서만 가능합니다.
- Cloudflare Access를 추가하려면 계정에서 Zero Trust를 활성화하고 관리 주소에 본인 이메일만 허용하는 정책을 설정합니다. 이 저장소의 `node home-server/setup-access.mjs 본인이메일`은 기존 Cloudflare 인증에 Access 설정 권한이 있을 때만 동작합니다. 기존 인증에 권한이 없으면 Cloudflare 대시보드에서 설정해야 합니다. Access 설정 전에도 자체 관리 비밀번호 인증이 적용됩니다.
- 관리 프로그램 실행 중에는 절전을 방지합니다. 노트북 전원 종료·덮개 닫기에 따른 절전·인터넷 단절 상태에서는 원격 접속할 수 없습니다.

## 저장·랭킹

- 학년·반·번호 조합으로 최초 제출 한 번만 저장합니다. 모든 화면에서 닉네임·동의 체크 입력을 받지 않습니다. 서버는 예전 기록과의 호환을 위해 선택적 닉네임 필드를 계속 지원합니다.
- 저장 내용: 접수번호, 학년·반·번호, 닉네임, 선택 답안, 문제 버전, 시작·접수 시각. 저장이 완료된 후 브라우저에서 점수와 해설을 보여줍니다.
- `GET /api/rankings`는 현재 문제 버전의 답안을 서버에서 채점해 순위·학생 정보·점수·소요 시간(`seconds`)을 반환합니다. 소요 시간은 시작·접수 시각 차이이며 이전 기록에 유효한 시각이 없으면 `null`(화면은 `—`)입니다. 답안 원문과 접수번호는 공개하지 않습니다.
- 점수 내림차순, 동점은 공동 순위이며 다음 점수는 바로 다음 등수입니다(1, 1, 1, 2, 2, 3). 같은 점수는 접수 순서로 나열합니다. 이전 기록에 닉네임이 없으면 대시(—)로 표시합니다.
- 랭킹은 3초마다 갱신합니다. 학생별 행을 재사용하고 보이는 학생 위치를 유지하며, 새 행은 해당 순위에서 등장하고 변경된 행은 이동·강조됩니다. 연결 실패 시 마지막 목록을 유지하고 연결 대기 상태를 표시합니다. 긴 목록은 초당 약 33px로 자동 이동하며 정지 버튼과 동작 줄이기 설정을 지원합니다.
- 집계 결과는 새 제출이 저장될 때만 다시 계산합니다. 데이터가 그대로면 화면 목록도 다시 만들지 않습니다. 빈 목록·정지 상태·숨겨진 탭에서는 자동 스크롤 프레임을 실행하지 않습니다.
- 신원 인증은 없습니다. 기존 DB와 이전 참여 제한은 그대로 보존합니다. 테스트는 별도의 임시 DB를 사용합니다.

저장 위치: `C:\scr\dokdo\responses.sqlite` (`DOKDO_DATA_DIR` 환경 변수로 변경 가능)

`export.bat`으로 학번·닉네임·문제 버전·선택번호 CSV를 `C:\scr\dokdo\exports`에 내보냅니다. CSV에는 점수를 저장하지 않으며, 닉네임이 수식으로 실행되지 않도록 처리합니다. 백업은 서버를 끈 후 저장 폴더 전체를 복사합니다. 기존 `%LOCALAPPDATA%\MaseokDokdo`의 응답과 CSV는 새 위치로 이전했고, 원래 파일과 `C:\scr\dokdo\backups`의 이전 전 DB 사본을 보존합니다.

터널 설정: `%LOCALAPPDATA%\MaseokDokdo\tunnel\config.yml`

Cloudflare 인증: `%USERPROFILE%\.cloudflared` (Git·배포 제외)

## 검증·배포

- `npm test`: 500명 저장, 동시 제출·중복 경합·재시도·재시작·이전 기록·닉네임·랭킹·CORS·로컬 API 연결 검사
- `npm run test:ui`: 6개 해상도에서 실제 임시 DB로 시작·문항 이동·4지선다/OX·제출·실패 후 재시도·결과·해설·중복 제한·랭킹을 검증합니다. 운영 데이터는 건드리지 않으며 화면 캡처는 `preview/ui/`에 생성합니다. Windows에서는 설치된 Chrome을 사용합니다. 다른 환경에서는 `npx playwright install chromium`을 먼저 실행합니다.
- `npm run test:ranking`: 3초 갱신·행 재사용·스크롤 위치 유지·새 행 등장·통신 실패·자동 이동·동작 줄이기를 검증합니다.
- `npm run build`: `public/`만 `dist/`로 파일별 복사하고 배포 CSS의 주석·불필요한 공백을 제거합니다. 사용하지 않는 이전 출력은 정리합니다. 정적 SVG에는 캐시를 적용합니다. 구글 드라이브에서 재귀 복사·삭제가 중단되는 문제를 피하도록 파일별로 처리합니다.
- 외부 폰트 다운로드 없이 시스템 한글 폰트를 사용합니다.

현재 디자인 기준과 프레임별 대응표는 `design/README.md`에 있습니다. 기존 누적 스타일과 화면 전환 보정 모듈은 `.local-archive/ui-before-20261025/`에 보존했으며 운영 화면에서 더 이상 불러오지 않습니다. 실제 수정은 `public/`에서 하고 `dist/`는 빌드로만 생성합니다.

사진 힌트 원본은 `assets/dokdo_hint_photo/`에 보존하고, 배포용 사본은 `public/assets/hints/`에 둡니다. 문제 연결은 `public/js/hints.mjs`에서 관리합니다. 힌트는 문제 아래에 표시하고 누르면 확대되며, 사진이 없는 문항에서는 숨깁니다. 문제·채점 데이터와 분리하여 사진 추가가 문제 버전이나 기존 랭킹에 영향을 주지 않습니다.
- Pages 프로젝트: `maseok-dokdo`, 저장소: `ryowoo2726-hue/dokdo`, 배포 브랜치: `main`
- Pages 빌드: `npm run build`, 출력: `dist`, 프레임워크: None

문제·정답은 공개 파일입니다. `public/data/questions.json`을 바꾸면 화면을 배포하고 노트북 서버도 재시작해야 합니다. 브라우저와 서버는 같은 문제 데이터의 SHA-256 버전을 사용합니다.

허용 출처는 학생 도메인·Pages 기본 도메인·로컬 API 주소입니다. `DOKDO_ALLOWED_ORIGINS`로 정확한 출처 목록을 설정할 수 있습니다. 학교 Wi-Fi와 외부 네트워크의 동시 부하는 현장에서 별도로 확인해야 합니다.
